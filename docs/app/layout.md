# Root Layout (`app/layout.tsx`)

The `RootLayout` component is the top-level layout wrapper for the application, defining global styling, root HTML structure, font configurations, and metadata.

## Import Dependencies

- `Metadata` from `next`: Defines page-level metadata.
- `Geist`, `Geist_Mono` from `next/font/google`: Configures font definitions.
- `./globals.css`: Loads global Tailwind CSS styles.

## Configurations

### Fonts
- **Geist Sans**: CSS variable `--font-geist-sans`
- **Geist Mono**: CSS variable `--font-geist-mono`

### Metadata
- **Title**: `Create Next App`
- **Description**: `Generated by create next app`

## Component Details

### `RootLayout`
Default exported React server component that wraps all page routes (`children`).

- **HTML Tag**: Configured with `lang="en"`, font CSS variables, `h-full`, and `antialiased` styling classes.
- **Body Tag**: Configured with `min-h-full flex flex-col` flexbox layout styles.
